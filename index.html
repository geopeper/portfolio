FIG. 01 — AGENT NAVIGATION, DA'AN DISTRICT25.026°N 121.534°E

01 · LLM × Agent-Based Modeling · 2026

Street-View-Aware Route Choice Simulation with LLM Agents

This project moves pedestrian simulation beyond shortest-path routing by introducing street-view perception into agent-based modeling. Through visual clustering and large language model agents, it simulates how different pedestrians may choose routes based on environmental experience, personal background, and memory.

Supervised by Dr. Sun, City Science Lab @ Taipei Tech

FIG. 02 — MISFIT INDEX, HONG KONG SAR22.302°N 114.177°E

02 · Spatial Analysis · 2025

When 15-Minute Cities Fail: Diagnosing Spatial Misfit in High-Density Urban Contexts

Using hourly GPS origin–destination data, grid-based accessibility indicators, and spatial statistics, this project shows that proximity does not guarantee use in a high-density, transit-oriented city — diagnosing where and why theoretical walking catchments fail to explain everyday mobility.

Supervised by Dr. Tianren Yang, The University of Hong Kong

  • 440k+ GPS Records
  • Gi* Hot-Spot Analysis
  • Multinomial Logit
  • Python / R / QGIS
